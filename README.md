# Square Image Tool

Turn a batch of mixed-size product photos into a set of square images. Keep the entire image with white padding, or crop from the center to fill the square. The default size is 1400 × 1400 pixels.

## Download and open

- **Windows and Mac** · [Download Square-Image-Tool.html](https://github.com/yyshuyejian-max/square-image-tool/releases/latest/download/Square-Image-Tool.html). Double-click the downloaded file to open it in your browser. Use a current version of Safari, Chrome, or Edge. The app works offline and processes photos on your device.
- **Windows desktop** · [Download Square-Image-Tool-Windows.exe](https://github.com/yyshuyejian-max/square-image-tool/releases/latest/download/Square-Image-Tool-Windows.exe). Open the executable to start. This build is unsigned. You can use the HTML download if your Windows security settings restrict unsigned programs.

## Make a batch

1. Drop in images or a folder, or use the file and folder buttons.
2. Choose **Fit with white padding** or **Fill with a center crop** and set the size.
3. Use **Download ZIP** in the browser app, or choose an output folder and run the batch in the Windows desktop app.

Start with JPEG or PNG images for consistent results across browsers.
